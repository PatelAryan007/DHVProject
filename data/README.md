# NIRF Dataset

Place the file `nirf_2017_2025_clean.csv` in this directory.

## Expected Columns

| Column | Type | Description |
|--------|------|-------------|
| Year | int | Ranking year (2017–2025) |
| Category | str | Institutional category |
| Institute_ID | str | Unique institution identifier |
| Name | str | Institution name |
| City | str | City |
| State | str | State |
| Score | float | Overall NIRF score |
| Rank | int | NIRF rank |
| TLR | float | Teaching, Learning & Resources |
| RPC | float | Research and Professional Practice |
| GO | float | Graduation Outcomes |
| OI | float | Outreach and Inclusivity |
| Perception | float | Perception score |
